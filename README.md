# Tokyo PS Cafe

Çekmeköy Tokyo PS Cafe web sitesi. PS5 masa, VIP loca, yarış simülasyonu ve PS5 kiralama.

- `index.html`: sitenin kendisi
- `images/`: logo, mekân fotoğrafları, favicon
- `images/oyunlar/`: oyun kapakları (isimler için `BENI-OKU.txt`)
- `KURULUM.txt`: yayınlama ve düzenleme rehberi

Instagram: [@tokyopscafe](https://www.instagram.com/tokyopscafe)
